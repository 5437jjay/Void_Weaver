                                          VOID WEAVER

Description: A simple 2-dimensional game made as a practice with a set of modules of mini-games followed by a single story.
Goal: To make a game using C++ programming for the class assignment.
Technology used: C programming, C++ programming, raylib, HPML, AI-Images.
Usage: Can be played on the website using link or the name of the website for fun. Anyone can use it without restrictions and confusions.
From Designer to Player:
1.	The story was a made up one from a imaginary story view of future and not something to be skipped.
2.	Use the headphones for sure to complete the task of the game. (Mandatory)
3.	The Second game was a Slightly Original Game named as Ultimate tic tac toe which has the same board of the existing large tic tac toe but we can access one at a time and until that piece of board is finished (either by a win or by lose) then we can select another board.
4.	For those who couldn’t complete the last game the answer was given in this ReadMe file at the last check out if needed.
